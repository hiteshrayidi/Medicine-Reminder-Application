💊 Medicine Reminder Application
A Java-based web application designed to help users manage their medicine schedules, receive timely reminders, track medicine intake, and maintain dose history.

📌 About the Project
The Medicine Reminder Application helps users remember their daily medicines and keep track of whether they have taken their scheduled doses.
Users can add medicine details, set reminder times using AM/PM, receive browser alarm notifications, and record their responses as Taken, Not Taken, or Snooze.
The application uses Java for backend processing and HTML, CSS, and JavaScript for the web interface.

 ✨ Features
- User Registration & Login:Create an account and securely access the application.
- Medicine Management:Add, edit, and delete medicine details.
- AM/PM Time Selection:Set medicine reminders using hours, minutes, and AM/PM.
- Scheduled Reminders:Receive reminders at the configured medicine time.
- Alarm Sound:Repeated alarm beeps while a reminder is awaiting a response.
- Dose Tracking:Choose one of the following responses:
  - ✅ Taken
  - ❌ Not Taken
  - ⏰ Snooze for 5 minutes
- Dose History:View previous medicine responses.
- Dashboard:View medicine information, adherence details, and daily dose information.
- Stock Management:Track available pills and receive low-stock warnings.
- CSV Export:Download dose history as a CSV file.
- Password Management:Change your account password.

🛠️ Technologies Used
Frontend - HTML, CSS, JavaScript 
Backend - Java 
Web Server - Java HttpServer 
Alarm Sound - JavaScript Web Audio API
Data Storage - Java Serialization

▶️ How to Run the Project
Step 1: Clone the repository
git clone YOUR_GITHUB_REPOSITORY_URL

Step 2: Open the project folder
Open the downloaded project folder in Visual Studio Code.

Step 3: Compile the Java file
Open the VS Code terminal and execute:
javac MedicineReminderWeb.java

Step 4: Run the application
java MedicineReminderWeb

Step 5: Open the website
The application displays a localhost URL in the terminal.
Open that URL in your browser to access the Medicine Reminder Application.

🔔 How to Use
1. Register a new account.
2. Log in using your credentials.
3. Add a medicine with its name and dosage.
4. Enter the reminder hour and minute.
5. Select AM or PM.
6. Choose the required days and save the medicine.
7. Open the reminder panel.
8. Click **Enable Alarm Sound** to allow browser audio.
9. When the reminder appears, select Taken, Not Taken, or Snooze.
10. Check the History section to review recorded doses.

 ⚠️ Important Notes
- Keep the Java application running while using the system.
- Keep the browser page open to receive reminders.
- Click Enable Alarm Sound once to allow the browser to play alarm sounds.
- The application currently runs as a local web application.
- Back up `users.dat` regularly to protect saved information.
- This application is a reminder and tracking tool, not a substitute for medical advice.
